# Spotter Freight Rate Prediction Challenge
**Machine Learning Engineer Technical Assessment**

This repository contains the end-to-end machine learning pipeline for predicting `posted_rate` on U.S. full truckload (FTL) freight loads.

---

## 1. Project Overview

The objective is to build, validate, and deploy a regression pipeline that accurately predicts posted freight rates (`posted_rate`) across diverse freight lanes, equipment types, and macroeconomic conditions:
- **Development Data (`train-test.csv`)**: 48,000 labeled loads from January 1, 2025 to October 31, 2025.
- **Evaluation Data (`validation.csv`)**: 12,000 unlabeled loads from November 1, 2025 to December 31, 2025.
- **Fixed-Lane Scenario (`december-chart-inputs.csv`)**: 31 daily loads across December 2025 for Lexington $\to$ Fort Wayne (360 miles, Dry Van, 32,000 lbs).

### Key Architectural Decisions:
- **Formulation**: Continuous regression evaluated via MAE, RMSE, MAPE, and $R^2$.
- **Validation Protocol**: Chronological out-of-time split (Jan–Aug train: 38,368 loads; Sep–Oct holdout: 9,632 loads) to prevent lookahead data leakage.
- **Primary Model**: `HistGradientBoostingRegressor` with MAE loss (`loss='absolute_error'`). It natively models non-linear mileage curves, handles categorical variables (`pickup`, `delivery`, `equipment`), and is robust against heavy-tailed spot rate outliers.
- **Feature Engineering**: Multiplicative market interactions (`quote_signal * distance`, `market_index * distance`), equipment-median weight imputation, month-median market index imputation, and cyclical calendar signals (`sin`/`cos`).
- **Feature Integrity**: All original columns (including `load_id`) are preserved throughout transformations; `load_id` is excluded from model feature sets.

## 3. Environment Setup & Dependencies

Python 3.10+ is recommended.

### 1. Clone & create virtual environment
```bash
# Navigate to project directory
cd "Spotter AI"

# Create a virtual environment
python -m venv .venv

# Activate the virtual environment
# Windows (PowerShell):
.\.venv\Scripts\Activate.ps1
# Windows (cmd):
.\.venv\Scripts\activate.bat
# Linux / macOS:
source .venv/bin/activate
```

### 2. Install required packages
```bash
pip install -r requirements.txt
```

## 4. How to Run

### Run the Jupyter Notebook (Complete Pipeline)
Open VS Code, select venv (that you created) as the base Kernel, then run [`complete_pipeline.ipynb`](complete_pipeline.ipynb).
The notebook executes end-to-end:
1. Loads and inspects labeled and validation data.
2. Performs exploratory data analysis and generates inline visualizations.
3. Fits the preprocessor and trains the models on the chronological split.
4. Benchmarks holdout error metrics and residual diagnostics.
5. Refits the model on all 48,000 labeled loads.
6. Generates `validation_predictions.csv` and `december_chart_predictions.csv`.
7. Saves the trained model artifacts (`model.joblib`).
8. Executes the official `score.py` validator and displays the candidate December chart.

**Expected Output:**
```
Validated 12,000 final predictions.
Validated 31 fixed December predictions.
Created chart: scorer_results/candidate_december.png
Final validation metrics are calculated by Spotter after submission.
```
